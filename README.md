# exploring-food-data-
I did an exploratory data analysis on data set food_coded_data.csv and evaluated data quality problems like missing values, Irregular cardinality and Outliers We cannot undertake data analysis without EDA because it helps us understand the underlying structure and patterns within the dataset, find problem areas, and make decisions regarding how to resolve them. Any subsequent data analysis will produce valid and important results only if the data is high quality. The reliability of conclusions may be affected if data quality problems are not appropriately managed. This report will describe the steps taken in performing EDA, such as doing descriptive statistics and visualizations, and how we have identified and fixed data quality issues to clean the dataset.
